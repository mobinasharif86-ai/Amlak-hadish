# دفتر املاک — معماری امن نهایی

مرورگر کاربر هیچ‌وقت مستقیم به دیتابیس Supabase وصل نمی‌شود. یک تابع سرور روی خود Supabase
(به اسم `office-api`، از قبل توسط دستیار مستقر شده) واسط امن است:

مرورگر  →  تابع office-api (روی Supabase)  →  دیتابیس (با کلید محرمانه، فقط سمت سرور)

هر درخواست باید رمز عبور معتبر (مدیر یا مشاور) همراهش باشد؛ تابع قبل از هر کاری این را چک می‌کند.
دسترسی مستقیم و عمومی به جدول `app_state` قفل است (RLS بدون هیچ policy مجاز).

## نکته‌ی مهم

این نسخه دیگر هیچ نیازی به تنظیم متغیر یا Secret در Cloudflare ندارد — نه برای زمان build،
نه برای زمان اجرا. فقط کافی است سایت را (به همان روش قبلی: Build command = `npm run build`,
Build output directory = `dist`) روی Cloudflare منتشر کنی.

اگر قبلاً متغیرهای `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `SUPABASE_URL`,
`SUPABASE_SERVICE_ROLE_KEY` را جایی اضافه کرده بودی، می‌توانی همه را حذف کنی — دیگر استفاده نمی‌شوند
(بی‌ضررند اگر هم بمانند).

## ساختار فایل‌ها

- `src/` — اپ ری‌اکت؛ با `fetch` مستقیم به تابع `office-api` روی Supabase وصل می‌شود.
- تابع `office-api` جدا از این ریپازیتوری، مستقیم روی پروژه‌ی Supabase مستقر شده است.
